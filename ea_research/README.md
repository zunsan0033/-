# IndexReversion_EA：米国株価指数 CFD の日足・短期逆張り EA

米国株価指数（US500＝S&P500 が主、NAS100 が副）を、売られすぎた日の終値で買い、反発したら手仕舞う EA です。買いのみで、ナンピン・マーチンゲール・グリッドは使いません。

ロジックを導いた過程と検証結果は [REPORT.md](REPORT.md) にまとめています。

| パス | 内容 |
|---|---|
| `mql5/IndexReversion_EA.mq5` | MT5 用 EA（両建て口座が必要） |
| `mql4/IndexReversion_EA.mq4` | MT4 用 EA（同じロジック） |
| `REPORT.md` | 研究レポート（仮説、検証手順、結果、限界） |
| `results/` | レポートの表とグラフの元データ（CSV・JSON・PNG） |
| `research/` | 検証コード（Python）。`run_all.py` で全結果を再現 |

## ロジック（日足が確定するたびに 1 回判定）

- **ルール A（IBS 逆張り）**
  - 買う条件：その日の終値が値幅の下位 20%（IBS＜0.20）
  - 手仕舞い：翌日の終値。翌日も条件を満たせば持ち越す
- **ルール B（RSI(2) 押し目買い）**
  - 買う条件：終値が 200 日移動平均より上、かつ RSI(2)＜10
  - 手仕舞い：終値が 5 日移動平均を上回った日。最長 10 日
- **損切り**：ルールごとに、シグナル終値 − 3×ATR(10) に業者側の損切りを置く

## 使い方（MT5）

1. `IndexReversion_EA.mq5` を `MQL5/Experts/` にコピーし、MetaEditor でコンパイルします（F7）。
2. US500（S&P500 の CFD）のチャートに EA を付けて、アルゴリズム取引を有効にします。
   - チャートの時間足は何でもかまいません（判定には日足を使います）。
   - 口座は**両建て（ヘッジング）口座**が必要です。ネッティング口座では起動しません。
3. まずストラテジーテスターで確認します。
   - モデル：「リアルティックに基づいた全ティック」または「1 分足 OHLC」
   - 期間：2015 年以降など
4. デモ口座で数か月のフォワードテストを行ってから、実口座を検討してください。

MT4 は `IndexReversion_EA.mq4` を `MQL4/Experts/` にコピーし、同じ手順で使います。

> **注意**：この EA は作成環境で MetaEditor のコンパイルを通していません。手続きは Python に逐語で書き写して、研究用シミュレーターと取引 1 件ずつ一致することを確認済みです。コンパイルでエラーや警告が出た場合はお知らせください。

## パラメータ

| 名前 | 初期値 | 意味 |
|---|---|---|
| `InpUseRuleA` / `InpUseRuleB` | true / true | 各ルールを使うか |
| `InpIbsThreshold` | 0.20 | ルール A：IBS がこの値未満で買う |
| `InpRsiPeriod` / `InpRsiThreshold` | 2 / 10 | ルール B：RSI の期間と、買う水準 |
| `InpTrendMaPeriod` / `InpExitMaPeriod` | 200 / 5 | ルール B：トレンド条件の移動平均、手仕舞いの移動平均 |
| `InpMaxHoldBarsB` | 10 | ルール B：最長の保有日数 |
| `InpSizing` | リスク % | 建玉の決め方（リスク % ／ 固定ロット） |
| `InpRiskPercent` | 1.0 | 損切りに達したときに失う資産の % （ルールごと） |
| `InpFixedLots` | 0.10 | 固定ロット方式のロット数（ルールごと） |
| `InpAtrPeriod` / `InpStopAtrMult` | 10 / 3.0 | 損切り幅＝ATR(10)×3 |
| `InpMaxLotsTotal` | 0 | この銘柄で EA が持つ合計ロットの上限（0＝なし） |
| `InpMaxSpreadPoints` | 0 | スプレッドがこれより広い間は待つ（0＝確認しない） |
| `InpMaxWaitMinutes` | 180 | 日足の始まりから何分まで新規エントリーを許すか |
| `InpSkipSundayBars` | true | 日曜の短い日足を判定に使わない（GMT サーバーの業者向け） |
| `InpMagicBase` | 26111700 | マジックナンバー（ルール A は＋1、ルール B は＋2） |

シグナルの値（IBS 0.20、RSI(2) 10、200・5 日移動平均）は文献どおりで、最適化していません。変えると検証結果の前提が崩れます。

**リスク % の目安**（REPORT.md 5.3 節）：

- 1% は動作確認用の控えめな値で、年率 1〜2% 程度です。
- 3% で年率 2.5〜5%、最大 DD は 13〜24% でした。
- リスクを上げると、DD もほぼ比例して増えます。

## MT5 から過去データを書き出す（`tools/ExportBars.mq5`）

MT5 の中で一度実行するだけで、指定した銘柄の過去データを CSV に書き出すスクリプトです。読み取り専用で、注文は一切出しません。

1. MT5 の「ツール」→「オプション」→「チャート」で「チャートの最大バー数」を「Unlimited」にし、MT5 を再起動します。
2. `ExportBars.mq5` を `MQL5/Scripts/` にコピーし、MetaEditor でコンパイルします（F7）。
   - フォルダは「ファイル」→「データフォルダを開く」で開けます。
3. US500 などのチャートに、ナビゲーターからスクリプトをドラッグします。
   - `InpSymbols` が空ならチャートの銘柄を書き出します。「US500,US100」のようにカンマ区切りで複数指定もできます。
   - 時間足は `InpTimeframe` で選びます。初期値は 5 分足です。
4. 書き出し先はデータフォルダの `MQL5/Files/` です。
   - `<銘柄>_M5.csv`：過去データ
   - `export_info.txt`：サーバー時刻と GMT の差、スプレッド、スワップ

## お使いの業者のデータで確かめる

MT5 の「銘柄」→「バー」から、US500 の日足を CSV で書き出します。MT4 なら「ヒストリーセンター」から書き出せます。次のコマンドで、同じロジックの成績を計算できます。

```sh
pip install numpy pandas scipy matplotlib arch
cd research
python run_all.py --csv /path/to/US500_D1.csv
```

`--csv` を付けずに実行すると、`arch` に同梱の S&P500・NASDAQ の日足だけで、レポートの表とグラフを `results/` に作り直します。US500 CFD の区分も再現する場合は、`--duka-root` に Dukascopy の日足ファイル（`raw/USA500IDXUSD/day/<年>_BID.bi5`）を置いたフォルダを指定してください。このファイルはリポジトリに含めていません。
