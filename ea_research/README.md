# IndexReversion_EA：米国株価指数 CFD の日足・短期逆張り EA

米国株価指数（US500＝S&P500 が主、NAS100 が副）を、売られすぎた日の終値で買い、反発したら手仕舞う EA です。買いのみで、ナンピン・マーチンゲール・グリッドは使いません。

ロジックを導いた過程と検証結果は [REPORT.md](REPORT.md) にまとめています。

| `mql5/IndexPortfolio_EA.mq5` | **3 つの戦略を 1 本にまとめた EA**（1 枚のチャートに付けるだけ。MT5。下の別章） |

## ロジック（日足が確定するたびに 1 回判定）

- **ルール A（IBS 逆張り）**
  - 買う条件：その日の終値が値幅の下位 20%（IBS＜0.20）
  - 手仕舞い：翌日の終値。翌日も条件を満たせば持ち越す
- **ルール B（RSI(2) 押し目買い）**
  - 買う条件：終値が 200 日移動平均より上、かつ RSI(2)＜10
  - 手仕舞い：終値が 5 日移動平均を上回った日。最長 10 日
- **損切り**：ルールごとに、シグナル終値 − 3×ATR(10) に業者側の損切りを置く

## 使い方（MT5）

1. `IndexReversion_EA.mq5` を `MQL5/Experts/` にコピーし、MetaEditor でコンパイルします（F7）。
2. US500（S&P500 の CFD）のチャートに EA を付けて、アルゴリズム取引を有効にします。
   - チャートの時間足は何でもかまいません（判定には日足を使います）。
   - 口座は**両建て（ヘッジング）口座**が必要です。ネッティング口座では起動しません。
3. まずストラテジーテスターで確認します。
   - モデル：「リアルティックに基づいた全ティック」または「1 分足 OHLC」
   - 期間：2015 年以降など
4. デモ口座で数か月のフォワードテストを行ってから、実口座を検討してください。

MT4 は `IndexReversion_EA.mq4` を `MQL4/Experts/` にコピーし、同じ手順で使います。

> **注意**：この EA は作成環境で MetaEditor のコンパイルを通していません。手続きは Python に逐語で書き写して、研究用シミュレーターと取引 1 件ずつ一致することを確認済みです。コンパイルでエラーや警告が出た場合はお知らせください。

シグナルの値（IBS 0.20、RSI(2) 10、200・5 日移動平均）は文献どおりで、最適化していません。変えると検証結果の前提が崩れます。

**建玉の目安**（REPORT.md 5.3 節）：

- v1.10 から、初期値は「資産の 0.5 倍/ルール」です。2 ルールとも持つと、建玉は最大で資産の 1 倍になります。
- 初期値の場合、利用中の業者の S&P500（2015〜2026 年）では年 5.0%、最大 DD −9.8% でした。
- 倍率を上げると、リターンも最大 DD もほぼ比例して増えます。

## IndexGrowth_EA：少額口座向けの成長型（MT5）

15 万円前後から増やすことを狙って、IndexPortfolio_EA の建玉を大きくした版です。売買のルールは同じで、変えたのは建玉の決め方だけです。根拠と試算は REPORT.md の第 11 章にあります。

**IndexPortfolio_EA との違い**

| 項目 | IndexPortfolio_EA | IndexGrowth_EA |
|---|---|---|
| 逆張りの建玉（1 ルールあたり） | 資産の 0.5 倍 | 資産の 1.0 倍 |
| 逆張り NASDAQ100 のルール B | 使う | 使わない（この期間、リスクのわりに利益が小さかったため） |
| 日中モメンタムの建玉 | 研究の 0.5 倍 | 研究どおり（1.0 倍） |
| 計算上のロットが最小ロット未満のとき | 見送る | 最小ロットの建玉が上限以内なら、最小ロットで入る（上限は US500 が資産の 2 倍、US100 が 3 倍、日中モメンタムが 4 倍） |
| 大きく減ったとき | 何もしない | 資産が最高値から 50% 減ったら、新規エントリーを止める（決済と損切りは続ける） |

15 万円では、4 つのポジションがすべて 0.1 ロットになります。資産に対する建玉は、US500 の 2 つが約 0.8 倍ずつ、US100 の 2 つが約 2.9 倍ずつです。資産が増えると、建玉は 0.1 ロットずつ自動で増えます。

**使い方**
1. `IndexGrowth_EA.mq5` を `MQL5/Experts/` にコピーしてコンパイルし、US100Cash のチャート 1 枚に付けます。
2. **ほかの EA（IndexReversion_EA・IntradayMomentum_EA・IndexPortfolio_EA）とは同時に動かさないでください。** マジックナンバーが同じなので、同じポジションを二重に管理してしまいます。
3. 口座は両建て（ヘッジング）型が必要です。
4. 4 つのポジションが同時に立つと、建玉は資産の約 7 倍になります（めったにありません）。口座のレバレッジ設定が、その証拠金に足りるか確かめてください。
5. 新規エントリーが止まった後に再開するには、2 つの方法があります。
   - 入金する（最高値との差が縮まり、自動で再開します）
   - MT5 の「ツール」→「グローバル変数」（F3）で `IG_peak_26111800` を削除して、最高値をリセットする

   出金した後も、出金額だけ「減った」と判断されるので、同じように削除してください。

**ストラテジーテスターで試すとき**
- 2018 年から 15 万円で回すと、当時は指数も円も安く、0.1 ロットの金額が今より小さかったため、今の条件より有利な結果になります。
- 今の条件に近い形で確かめるなら、期間を 2025 年 1 月以降にしてください。

**リスク**：少額から大きく増やせる可能性がある一方で、資金を大きく減らす可能性も十分にあります。

- 試算では、3 年後に元本を割る確率が、優位性が過去どおりなら約 3%、半分に減れば約 22% でした。
- 試算は過去の日々の値動きを並べ替えたものなので、過去にない規模の暴落は含みません。逆張りの買い（US100 で約 2.9 倍、US500 で約 0.8 倍）が同時に立っている日に、指数が窓を開けて 10% 下がると、損切りが間に合わず、1 日で資産の 3〜4 割を失うこともありえます。
- 失っても生活に困らない資金で使ってください。

## IndexPortfolio_EA：3 つの戦略を 1 本で動かす EA（MT5）

次の 3 つを、1 枚のチャートに付けるだけで同時に動かします。中身のロジックとマジックナンバーは、単体の EA と同じです。

| モジュール | 戦略 | 銘柄 |
|---|---|---|
| 1 | IndexReversion（日足の逆張り） | S&P500（初期値 US500Cash） |
| 2 | IndexReversion（日足の逆張り） | NASDAQ100（初期値 US100Cash） |
| 3 | IntradayMomentum（日中モメンタム。建玉は研究の 0.5 倍が初期値） | NASDAQ100（初期値 US100Cash） |

**使い方**
1. `IndexPortfolio_EA.mq5` を `MQL5/Experts/` にコピーし、コンパイルします（F7）。
2. **US100Cash のチャート 1 枚**に付けます。時間足は何でもかまいません。US500Cash の売買も、この 1 枚から行います。
3. 銘柄名が業者で違う場合は、`InpSymbolSPX` と `InpSymbolNDX` を気配値表示の名前に合わせます。
4. 使わないモジュールは、`InpRunReversionSPX`・`InpRunReversionNDX`・`InpRunMomentumNDX` を false にします。
5. **単体の IndexReversion_EA・IntradayMomentum_EA とは同時に動かさないでください。** マジックナンバーが同じなので、同じポジションを二重に管理してしまいます。単体の EA を外してから付けてください。今あるポジションは、そのまま引き継げます。

**ストラテジーテスター**
- 銘柄は **US100Cash** を選びます（US500Cash のデータは、テスターが自動で読み込みます）。
- モデルは「リアルティックに基づいた全ティック」にします。
- 初期資金は、ロットの刻みで成績がゆがまない額（例：1,000 万円）にしてください。

**口座**：両建て（ヘッジング）口座が必要です。3 つを全部動かすなら、資金は 100 万円以上が目安です（最小ロットの都合）。

**主な追加設定**

| 名前 | 初期値 | 意味 |
|---|---|---|
| `InpSymbolSPX` / `InpSymbolNDX` | US500Cash / US100Cash | 業者での銘柄名 |
| `InpRunReversionSPX` / `InpRunReversionNDX` / `InpRunMomentumNDX` | すべて true | 各モジュールを動かすか |
| `InpExposureScale` | **0.5** | 日中モメンタムの建玉の倍率（単体 EA の初期値 1.0 の半分） |
| `InpMaxTotalExposure` | 0 | 3 つ合計の建玉の上限（資産の何倍か。0＝なし）。これを超える分は新規に入らない |

ほかのパラメータは、単体の 2 つの EA と同じ名前・同じ意味です（日中モメンタムのスプレッド上限は `InpMaxSpreadPointsIM`）。

## IntradayMomentum_EA：NASDAQ100 の日中モメンタム EA（MT5）

ニューヨーク時間の取引時間中だけ動く順張りの EA です。値動きが普段の揺れ幅（ノイズ帯）を超えたら、その方向に乗ります。ポジションは毎日 16:00 に必ず決済し、持ち越しません。検証の詳細は REPORT.md の 8.3 節と第 9 章にあります。

**ロジック**（研究のルールのまま）
- 9:30 の始値と前日 16:00 の終値をもとに、「ノイズ帯」の上限と下限を作ります。幅は、過去 14 日の「同じ時刻までの値動きの平均」です。
- 10:00〜15:30 の 30 分ごとに判定します。
  - 価格が「上限と VWAP の高い方」より上なら買い
  - 価格が「下限と VWAP の低い方」より下なら売り
  - それ以外は持たない
- 建玉の大きさ：資産の min(4, 2% ÷ 過去 14 日の日次変動率) 倍。研究の期間（NASDAQ100）では平均 2.0 倍でした。
- 損切り：建値から 2% の位置に、業者側の損切りを置きます。研究の期間で発動したのは 10 年で 7 回でした。
- 米国市場の祝日と短縮取引日は取引しません。

**使い方**
1. `IntradayMomentum_EA.mq5` を `MQL5/Experts/` にコピーし、MetaEditor でコンパイルします（F7）。
2. NASDAQ100 の CFD（例：US100Cash）のチャートに付けます。時間足は何でもかまいません（判定には 5 分足を使います）。
3. **業者のサーバー時刻を正しく設定してください。** ニューヨーク時間を求めるのに使います。
   - 冬に GMT+2、夏に GMT+3 になる業者（多くの業者がこれです）は、初期値（`InpServerWinterGMT`=2、`InpServerDST`=EU）のままで大丈夫です。
   - 確認するには、チャートの 5 分足でティック数が急に増える足を探します。ニューヨーク 9:30 の寄り付きは、このタイプのサーバーでは通常 16:30（3 月と 11 月初めの数週間は 15:30）に来ます。
4. ストラテジーテスターでは、モデルを「リアルティックに基づいた全ティック」か「1 分足 OHLC」にしてください。
5. まずデモ口座で数か月試し、研究の結果と大きく違わないかを確認してから、実口座を検討してください。

**パラメータ**

| 名前 | 初期値 | 意味 |
|---|---|---|
| `InpServerWinterGMT` | 2 | 業者のサーバー時刻の、冬の GMT との差（時間） |
| `InpServerDST` | EU | サーバー時刻が夏時間で 1 時間進む日程（EU ／ US ／ なし） |
| `InpSessionStartMin` / `InpSessionEndMin` | 570 / 960 | 取引時間（ニューヨーク時間の 0 時からの分。9:30 と 16:00） |
| `InpLookbackDays` | 14 | ノイズ帯と変動率の計算に使う日数（研究の値。変えない） |
| `InpTargetDailyVol` | 2.0 | 目標とする日次の変動率（%）。建玉＝これ÷過去 14 日の変動率 |
| `InpMaxLeverage` | 4.0 | 建玉の上限（資産の何倍か） |
| `InpExposureScale` | 1.0 | 建玉全体にかける倍率。0.5 にすると研究の半分の大きさ |
| `InpStopPct` | 2.0 | 損切りの位置（建値から何 %）。0 で損切りなし |
| `InpMaxLots` | 0 | ロット数の上限（0＝なし） |
| `InpMaxSpreadPoints` | 0 | スプレッドがこれより広いときは新規に入らない（0＝確認しない） |
| `InpMaxDelayMin` | 5 | 判定時刻からこの分数を過ぎたら新規に入らない（再起動直後などのため） |
| `InpSkipUSHolidays` | true | 米国市場の祝日と短縮取引日は取引しない |
| `InpMagic` | 26111800 | マジックナンバー（IndexReversion_EA とは別の値） |

**注意**
- **コストに敏感です。** 研究では、NASDAQ100 で往復コストが 1bp 増えるごとに、シャープが約 0.45 下がりました。スプレッドの広い業者や口座では使わないでください。
- **S&P500 には使いません。** 論文の公表後（2024 年 6 月以降）は、S&P500 ではコストを引く前でも効果がほぼ消えていました。
- **建玉が大きくなる日があります。** 変動が小さい日は、最大で資産の 4 倍の建玉になります。実口座では、`InpExposureScale` を 0.5 などに下げて始めることを勧めます。
- この EA も、作成した環境ではコンパイルを試せていません。手順は Python に書き写し、研究のコードと取引が 1 件ずつ一致することを確認済みです。

## MT5 から過去データを書き出す（`tools/ExportBars.mq5`）

MT5 の中で一度実行するだけで、指定した銘柄の過去データを CSV に書き出すスクリプトです。読み取り専用で、注文は一切出しません。

1. MT5 の「ツール」→「オプション」→「チャート」で「チャートの最大バー数」を「Unlimited」にし、MT5 を再起動します。
2. `ExportBars.mq5` を `MQL5/Scripts/` にコピーし、MetaEditor でコンパイルします（F7）。
   - フォルダは「ファイル」→「データフォルダを開く」で開けます。
3. US500 などのチャートに、ナビゲーターからスクリプトをドラッグします。
   - `InpSymbols` が空ならチャートの銘柄を書き出します。「US500,US100」のようにカンマ区切りで複数指定もできます。
   - 時間足は `InpTimeframe` で選びます。初期値は 5 分足です。
4. 書き出し先はデータフォルダの `MQL5/Files/` です。
   - `<銘柄>_M5.csv`：過去データ
   - `export_info_M5.txt`（時間足ごと）：サーバー時刻と GMT の差、スプレッド、スワップ

## お使いの業者のデータで確かめる

MT5 の「銘柄」→「バー」から、US500 の日足を CSV で書き出します。MT4 なら「ヒストリーセンター」から書き出せます。次のコマンドで、同じロジックの成績を計算できます。

```sh
pip install numpy pandas scipy matplotlib arch
cd research
python run_all.py --csv /path/to/US500_D1.csv
```

`--csv` を付けずに実行すると、`arch` に同梱の S&P500・NASDAQ の日足だけで、レポートの表とグラフを `results/` に作り直します。US500 CFD の区分も再現する場合は、`--duka-root` に Dukascopy の日足ファイル（`raw/USA500IDXUSD/day/<年>_BID.bi5`）を置いたフォルダを指定してください。このファイルはリポジトリに含めていません。
