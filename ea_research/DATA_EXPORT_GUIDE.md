# 上位 3 候補の検証用データを MT5 から書き出す手順

対象：CANDIDATES.md の A（日中モメンタム）・B（トレンドフォロー）・C（今の EA を他の指数に展開）
所要時間：30〜60 分（大半は待ち時間）

- 使うスクリプト（`tools/ExportBars.mq5`）は読み取り専用で、注文は一切出しません。
- デモ口座でかまいません。同じ業者なら、デモでも本番でも価格データは同じです。

## 必要なデータ

| 候補 | 時間足 | 銘柄 |
|---|---|---|
| A 日中モメンタム | 5 分足 | S&P500、NASDAQ100（余裕があればダウ、DAX も） |
| B トレンドフォロー | 日足 | 株価指数（S&P500、DAX、日経平均、FTSE）、主要通貨 7 ペア、金、銀、原油 |
| C 他の指数に展開 | 日足 | S&P500、NASDAQ100、ダウ、ラッセル 2000、DAX、日経平均、FTSE、STOXX50 |

B と C の日足は、まとめて 1 回で書き出せます。スクリプトの実行は 5 分足で 1 回、日足で 1 回の計 2 回です。

## 1. MT5 の設定（初回だけ）

1. MT5 を開いて、口座にログインします。
2. 「ツール」→「オプション」→「チャート」タブで、「チャートの最大バー数」を「Unlimited」にして「OK」を押します。
3. MT5 をいったん閉じて、もう一度開きます。この設定をしないと、最近の一部の足しか取れません。

## 2. スクリプトを入れる

1. ブラウザで次のページを開き、右上の「↓」（Download raw file）を押して保存します。
   https://github.com/zunsan0033/-/blob/claude/wonderful-hopper-u4u5yt/ea_research/tools/ExportBars.mq5
2. MT5 の「ファイル」→「データフォルダを開く」で開いたフォルダの中の「MQL5」→「Scripts」に、保存した `ExportBars.mq5` を移します。
3. MT5 の「ツール」→「MetaQuotes Language Editor」（F4）で MetaEditor を開きます。
4. MetaEditor の左側の「ナビゲーター」で「Scripts」→「ExportBars.mq5」を開き、「コンパイル」（F7）を押します。
5. 下の「エラー」タブに「0 errors」と出れば成功です。
   - エラーが出たら、その行をそのまま送ってください。作成時にコンパイルを試せていないためです。
6. MT5 に戻り、「ナビゲーター」（Ctrl+N）の「スクリプト」に ExportBars があることを確かめます。見当たらなければ、右クリックして「更新」を押します。

## 3. 銘柄名を調べる

銘柄名は業者によって違います。たとえば S&P500 は US500、US500Cash、SP500、SPX500 などです。

1. 「表示」→「銘柄」（Ctrl+U）を開き、検索欄で探します。

   | 必要なもの | 探す語の例 |
   |---|---|
   | S&P500 | 500、SPX |
   | NASDAQ100 | 100、NAS、USTEC |
   | ダウ | 30、DJ |
   | ラッセル 2000 | 2000、RUS |
   | ドイツ DAX | GER、DE40、DAX |
   | 日経平均 | 225、JPN |
   | 英国 FTSE | UK100、FTSE |
   | 欧州 STOXX50 | EU50、STOXX |
   | 金・銀 | XAU、GOLD、XAG、SILVER |
   | 原油 | WTI、OIL、BRENT |
   | 主要通貨 | EURUSD、USDJPY、GBPUSD、AUDUSD、USDCAD、USDCHF、NZDUSD |

   通貨は、業者によって末尾に記号が付きます（例：EURUSD.m、EURUSDm）。
2. 限月の付いた先物型（例：US500-DEC26、US500Z26）ではなく、期限のない「Cash」や現物型の銘柄を選びます。
3. 見つからない銘柄は飛ばしてかまいません。
4. 見つかった名前を、メモ帳にカンマ区切りで並べておきます（例：`US500Cash,US100Cash`）。

## 4. 5 分足を書き出す（候補 A 用）

1. 適当なチャートを 1 つ開きます。銘柄と時間足は何でもかまいません。
2. 「ナビゲーター」の ExportBars を、そのチャートにドラッグします。
3. 開いた画面の「入力」タブを次のように設定して、「OK」を押します。

   | 項目 | 設定 |
   |---|---|
   | InpSymbols | S&P500 と NASDAQ100 の名前（例：`US500Cash,US100Cash`）。余裕があればダウと DAX も足す |
   | InpTimeframe | M5（5 分） |
   | InpFrom | 2012.01.01（初期値のまま） |
   | InpTo | 1970.01.01 00:00（初期値のまま。「現在まで」の意味） |

4. チャートの左上に進み具合が出ます。数分〜30 分ほどかかることがあります。
5. 終わったら、「ツールボックス」（Ctrl+T）の「エキスパート」タブで、銘柄ごとに次のような行を確認します。

   `ExportBars: US500Cash M5 -> MQL5\Files\US500Cash_M5.csv  bars=…  first=…  last=…  failed_chunks=0`

   - `first`（いつから取れたか）と `last`（いつまでか）を控えておいてください。
   - `failed_chunks` が 0 でないときは、同じ設定でもう一度実行します。2 回目は速く終わります。

## 5. 日足を書き出す（候補 B・C 用）

1. もう一度、ExportBars をチャートにドラッグします。
2. 「入力」タブを次のように設定して、「OK」を押します。

   | 項目 | 設定 |
   |---|---|
   | InpSymbols | 株価指数 8 つ、主要通貨 7 ペア、金、銀、原油（WTI と Brent）の名前をすべてカンマ区切り |
   | InpTimeframe | D1（日足） |
   | InpFrom | **2000.01.01 に変更** |
   | InpTo | 初期値のまま |

3. 1〜2 分で終わります。4 と同じように「エキスパート」タブで確認します。

## 6. ファイルをまとめる

1. 「ファイル」→「データフォルダを開く」→「MQL5」→「Files」を開きます。
2. 次のファイルができています。
   - `銘柄名_M5.csv`：5 分足。1 銘柄で数十 MB あります。
   - `銘柄名_D1.csv`：日足。
   - `export_info_M5.txt`、`export_info_D1.txt`：業者名、サーバー時刻と GMT の差、スプレッド、スワップ。口座番号は含みません。
3. ファイルを右クリックし、「送る」→「圧縮（zip 形式）フォルダー」で zip にします。
   - 5 分足は 1 銘柄ずつ zip にします。GitHub は 1 ファイル 25 MB までのためです。
   - 日足と export_info は、1 つの zip にまとめてかまいません。

## 7. 私に送る

今の「-」リポジトリは**公開**なので、ここには上げないでください。業者のデータと業者名が、誰でも見られる状態になってしまいます。

- **方法 1**：このチャットにファイルを添付できるなら、それが一番簡単です。
- **方法 2**：GitHub に非公開のリポジトリを作って、そこにアップロードします。
  1. github.com の右上の「＋」→「New repository」を押します。
  2. 名前（例：`ea-data`）を入れ、「Private」を選んで「Create repository」を押します。
  3. 表示された画面の「uploading an existing file」を押し、zip をドラッグして「Commit changes」を押します。
  4. このチャットで「ea-data に上げた」と送ってください。私がこのセッションに追加して読み込みます。読み込めない場合は、Claude の GitHub アプリにそのリポジトリへのアクセスを許可する手順を、その時に案内します。

## 送ってもらった後に私がやること

- **候補 A**
  - サーバー時刻をニューヨーク時間に直し、CANDIDATES.md のルールどおりに検証します。
  - コストは、CSV のスプレッド列から計算します。
  - 論文の公表（2024 年）より前と後に分けて評価します。
- **候補 B**：15 銘柄のトレンドフォローを、スプレッドとスワップ込みで検証します。今の EA と組み合わせた場合も計算します。
- **候補 C**：今の EA を各指数で検証します。US500 では、REPORT.md とほぼ同じ結果になるかも確かめます（業者のデータが正しく取れているかの確認を兼ねます）。
- 結果は REPORT.md に追記し、有望なものは EA にします。
